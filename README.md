# Governance-Centric AI Orchestration Framework (GAOF)

GAOF is a reference architecture for governed AI workflows. It separates enterprise AI systems into six runtime layers:

1. Governance
2. Orchestration
3. AI Reasoning
4. Validation
5. Observability
6. Rollback

The goal is to make AI workflows policy-aware, auditable, observable, validated, and recoverable.
